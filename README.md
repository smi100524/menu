# 大锅菜菜谱系统 · 松岗基地

职员餐周菜单 + 智能配菜系统（大锅菜版）。

## 功能
- 本周菜单：每周 7 天 × 中餐/晚餐，每天都有「辣菜（湘菜）」和「粤菜」，另配青菜、例汤、主食和固定咸菜（小菜）。
- 智能配菜：选蔬菜类 + 荤食类，自动生成菜名、配料、调料、做法，并支持大锅菜按人数换算用量。
- 菜谱库：63 道菜，可按菜品分类（大荤/小荤/素菜/青菜/汤/主食/小菜）和菜系筛选。
- 食材分类库：蔬菜类、畜禽肉类、水产类、蛋品类、豆制品类、干货副食品。

## 打开方式
- 交互版：`index.html`（或 `菜单系统.html`）
- 静态版：`menu-static.html`

## GitHub Pages
将仓库 Pages 设置为根目录（`/`）即可，入口文件为 `index.html`。
