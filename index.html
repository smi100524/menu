菜谱库

小炒牛肉 大荤 辣菜

配料：牛肉片300克、辣椒2个、小米椒2个、蒜3瓣、姜1小块

调料：生抽1勺、蚝油1勺、料酒1勺、淀粉1勺、盐适量、食用油适量

  1. 牛肉切片，加生抽、料酒、淀粉抓匀腌10分钟
  2. 热锅冷油滑炒牛肉至变色盛出
  3. 爆香姜蒜，下辣椒炒至断生
  4. 倒入牛肉翻炒，加蚝油、盐调味即可
辣椒炒肉 大荤 辣菜

配料：猪前腿肉300克、辣椒2个、蒜3瓣、豆豉少许

调料：生抽2勺、老抽半勺、盐适量、食用油适量

  1. 猪肉切薄片，肥瘦分开；辣椒切滚刀块
  2. 干锅煸香辣椒至虎皮状盛出
  3. 先煸肥肉出油，再下瘦肉炒至变色
  4. 放蒜、豆豉、辣椒翻炒，加生抽、老抽、盐调味

  3. 下青椒翻炒至断生，倒回鸡蛋
  4. 加生抽、盐炒匀即可
